# 0thorderlogic.github.io — Redirect Repo

This repository exists solely to redirect visitors from the old GitHub Pages domain to the current site.

## Background

This site was originally hosted at `0thorderlogic.github.io` via GitHub Pages. When the custom domain `a115.xyz` was acquired, the project repo (`a115.xyz`) was pointed to it — which caused `0thorderlogic.github.io` to go dark, since GitHub Pages only serves one domain per repo.

Rather than losing traffic from people who bookmarked or linked to the old address, this repo was created to catch those visits and redirect them.

## The actual site

The live site is at **[a115.xyz](https://a115.xyz)** — built with [Astro](https://astro.build).
